# Application Summary

This file contains short project descriptions that can be reused in a CV, cover letter, GitHub profile, or Ausbildung interview.

## One-Line Description

**English:** A Chrome extension and cloud review system for learning German vocabulary from real online articles.

**Deutsch:** Eine Chrome-Erweiterung mit Cloud-Synchronisation und Telegram-Wiederholungen zum Deutschlernen anhand echter Online-Artikel.

## CV Bullet Points

**English:**

- Built a Chrome Extension with Manifest V3 for context-aware German vocabulary learning.
- Integrated Gemini API for Chinese explanations, Web Speech API for German pronunciation, and `chrome.storage.local` for offline vocabulary storage.
- Developed a Node.js / Express backend with PostgreSQL for cloud synchronization.
- Deployed the backend on a VPS with Docker, Caddy HTTPS reverse proxy, PM2 process management, and Telegram Bot review messages.
- Used Git and GitHub to manage project versions and deployment workflow.

**Deutsch:**

- Entwicklung einer Chrome-Erweiterung mit Manifest V3 zum kontextbezogenen Lernen deutscher Vokabeln.
- Integration der Gemini API fuer chinesische Erklaerungen, der Web Speech API fuer deutsche Aussprache und `chrome.storage.local` fuer lokale Speicherung.
- Aufbau eines Node.js-/Express-Backends mit PostgreSQL zur Cloud-Synchronisation.
- Deployment auf einem VPS mit Docker, Caddy als HTTPS-Reverse-Proxy, PM2-Prozessverwaltung und Telegram-Bot-Erinnerungen.
- Nutzung von Git und GitHub fuer Versionsverwaltung und Deployment-Workflow.

## Interview Explanation

**English:**

I built this project because I often read German articles and wanted to save useful vocabulary without interrupting my reading. The extension translates selected words in context, stores them locally, and can sync them to my VPS. The backend stores the vocabulary in PostgreSQL and sends Telegram review messages. This helped me practice frontend, backend, database, deployment, and API integration in one realistic project.

**Deutsch:**

Ich habe dieses Projekt gebaut, weil ich beim Lesen deutscher Artikel neue Vokabeln direkt speichern und spaeter wiederholen wollte. Die Erweiterung uebersetzt markierte Woerter im Kontext, speichert sie lokal und kann sie mit meinem VPS synchronisieren. Das Backend speichert die Vokabeln in PostgreSQL und sendet Wiederholungen ueber Telegram. Dadurch konnte ich Frontend, Backend, Datenbank, Deployment und API-Integration in einem realistischen Projekt ueben.
