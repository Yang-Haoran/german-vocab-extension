# Roadmap

## English

- Export and import vocabulary as JSON.
- Add a model benchmark tool for comparing Gemini and Gemma models.
- Add spaced repetition fields such as difficulty, review count, and next review date.
- Add cloud sync through a small backend API.
- Add a Telegram bot for daily vocabulary review.
- Add CSV or Anki export.
- Improve the project structure with TypeScript and automated tests.

## Deutsch

- Vokabeln als JSON exportieren und importieren.
- Ein Benchmark-Tool fuer Gemini- und Gemma-Modelle hinzufuegen.
- Felder fuer Spaced Repetition ergaenzen, z. B. Schwierigkeit, Wiederholungen und naechstes Wiederholungsdatum.
- Cloud-Synchronisation ueber eine kleine Backend-API ergaenzen.
- Einen Telegram-Bot fuer taegliche Wiederholungen bauen.
- CSV- oder Anki-Export ergaenzen.
- Projektstruktur mit TypeScript und automatisierten Tests verbessern.
